## 系统（GEO 智控台 V3.2 · 生产版）

**一键生产能力（点按钮=真实动作）**：
- **① 一键诊断**（诊断→一键诊断）：填官网域名+品牌词 → 真实 HTTP 探测（HTTPS/robots/WAF拦截/llms.txt/服务端渲染/Schema/标题/图片alt）+ 品牌词真实搜索 → 每项附证据 → 自动回填30项体检表 → 可下载报告直接发 IT/外包整改。
- **② 一键提升包**（行动→一键提升包）：点一次生成6个可部署文件——robots AI放行片段（交IT）/ llms.txt / Schema结构化数据 / 一园一档 / 选址FAQ20问 / 渠道分发作战包；配套**渠道作战图**8个真实入口（公众号/知乎/头条/百家号/CSDN/抖音/百科/企查查，含每渠道首发内容建议）；附内容Brief工单。
- **③ 一键跑30问**（监测）：逐条真实搜索30问（进度条可见），自动写入台账并统计自有阵地命中率；双周一轮看趋势。

**信息架构（金字塔）**：一级导航 4+1 —— 工作台（三步生产向导+状态）/ Ⅰ 诊断（一键诊断·30项体检·口径表·内容评分）/ Ⅱ 行动（一键提升包·90天方案·Agent团）/ Ⅲ 监测（30问批量+人工台账+热力+趋势）+ 知识库。

**启动**：`cd system && python3 server.py` → 浏览器开 `http://localhost:8340`（服务器模式：一键诊断/30问真实搜索可用，团队共享 SQLite 数据）。或双击 `index.html` 本地模式（除真实探测外全部可用）。

**多团队协作（v3.3）**：数据保存采用乐观锁（版本号 + 409 冲突检测），冲突时前端自动做字段级合并——台账取并集（任何人的录入都不丢），体检/口径表等改动字段以最后编辑者为准并提示；并发实测零丢失。对话模型在服务启动时自动预载（首问约 1–5 秒）。所有可下载文件均有「复制内容」兜底按钮（不受浏览器下载设置影响）。

**能力边界（诚实说明）**：六大AI引擎无公开问答API——「搜索通道素材池检测」可全自动，豆包/DeepSeek等最终提及率需人工提问录入（监测页②区，30问可一键复制）；系统内评分/Brief/方案为确定性规则引擎（21项全链路测试通过：`python3 test_e2e.py`）；真AI走 ZCode skill `/geo-agent` 与4个Agent提示词。

**视觉**：招商蓝/金（#014070/#AA9168，采样自招商局集团官方VI素材像素）。双端适配：桌面≥1024多栏；手机≤768单栏触控。

## Agent 与内置助手（三种用法）

| 用法 | 位置 | 适合 |
|---|---|---|
| **内置对话助手** | 任一页面右下角「问」悬浮窗（或行动→Agent团→「打开助手对话窗」） | 日常即问即答：怎么用系统、解读诊断结果、下一步做什么——本机 Ollama 模型驱动（qwen3.5:9b），已注入你的实时数据（体检分/提及率/诊断项） |
| **4个专业Agent提示词** | 行动 → ③ GEO Agent 团 | 重任务：长文案生产、批量改写——复制到豆包/Kimi/DeepSeek/ChatGPT 新对话即用 |
| **/geo-agent skill** | ZCode 编程助手内 | 让 AI 直接执行：出方案、改写评分、导出报告 |

内置助手依赖：`python3 server.py`（服务器模式）+ 本机 Ollama 运行中（`ollama serve`；模型缺失时按提示 `ollama pull qwen3:4b-instruct-2507-q4_K_M`）。对话记录存本机浏览器。

## 快速开始（首次使用三步）

1. 读 `GEO实操方案V2-招商产园.md` 第 0、8 节（决策者摘要 + 本周清单）；
