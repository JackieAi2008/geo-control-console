# SKIPGEO Golden Set 判分表（30 题 × 3 轮，逐要点判定）

- 被测：生产 geo.alaa.org.cn v0.1.11；2026-09-06 执行
- 两个被测通道：
  - 「对话助手」：KB 判定在前端 `kbSearch()`（生产 chat-kb.js，md5=本地）；命中→输出=词条原文（确定性模板，不调 LLM）；未命中→`POST /api/chat`（admin 个人 DeepSeek deepseek-v4-flash，SSE 流式）。本次以与前端 `parseSSEChunk+acc+=data` 等价的解析逐字复现。
  - 「AI代问」：`POST /api/answerbot/start`，豆包联网通道。
- 3 轮 = 3 个独立会话（每轮单独请求）；联网题第 2/3 轮用**标注的改写变体**（24h 缓存键=promptId+问题文本，原题重复只会命中缓存，测不到稳定性）。
- 判分规则：只判**期望要点是否在答案原文中字面出现**；题目级 pass = 要点命中 ≥50%。空回答（0 字符）= fail 并单列。
