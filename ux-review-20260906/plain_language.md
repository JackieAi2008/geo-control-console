# plain_language.md · 大白话审计（术语表）

- 审计对象：v0.1.11 全部走查过的屏幕文案，逐字摘抄
- 读者设定：**园区品宣岗**（写公众号、对接领导、不懂 SEO/编程/数据行话）——任务书指定背景
- 总评：这套文案整体在大白话化上做得**认真**——绝大多数术语带了括号注释（如「口径骨架（10 分钟）」「提及=1 / 相似=0.5」），还有「改写示范：营销腔 → GEO体」这种教学设计。下表只列**注释仍不够**或**注释本身更难懂**的词。
- 严重度：★★★=卡片/结论区高频出现，必改；★★=有注释但注释绕；★=低频或目标读者其实懂

## 改写示范（系统自带的，值得表扬并推广到更多位置）

内容评分页自带「改写示范：营销腔 → GEO体」，改写前 33 分、改写后 83 分，改写后文本逐字：

> 「蛇口网谷是招商蛇口产业园区（招商产园）旗下科创园区，位于深圳南山区。截至2025年11月，园区入驻企业近460家…（来源：中国工业新闻网，2025）」
